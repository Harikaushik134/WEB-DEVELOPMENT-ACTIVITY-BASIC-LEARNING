3. Online Learning Platform Interface
5. Digital Library Management Interface

Each project has:
- index.html

- 

HOW TO RUN
1. Open the project folder you want.
2. Open index.html in a browser.
   Recommended: open the folder in Visual Studio Code and use the Live Server extension.

CUSTOMIZE
- Portfolio: replace "Your Name", education, skills, projects and contact details with your own.
- Online Learning: edit course names, instructors and lesson details in index.html.
- Digital Library: edit the book cards and categories in index.html.
- Colors and layout can be changed in style.css.

NOTE
These are front-end demonstration projects. The portfolio contact form shows a demo confirmation;
course buttons show demo notifications; the library saves books only for the current page session.
Real email delivery, enrollment, accounts, and library database functions need a backend.
